# abbellisci-editoria-tallone

Strania la forma di una pagina verso un futurismo essenziale, su un livello da 0 a 100 ricavato dai manifesti di Marinetti, e lascia leggibile ogni parola.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Estrange a page with essential futurism](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/abbellisci-editoria-tallone). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install abbellisci-editoria-tallone@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install abbellisci-editoria-tallone@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Per avere tutte le skill della libreria installa `tutte-le-skill@ch-labs-skills`. Con altri agenti copia la cartella `skills/abbellisci-editoria-tallone` tra le skill dell'agente, per esempio in `~/.codex/skills/abbellisci-editoria-tallone`.
