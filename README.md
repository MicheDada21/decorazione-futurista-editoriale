# decorazione-futurista-editoriale

Strania la forma di una pagina verso un futurismo essenziale, su un livello da 0 a 100 ricavato dai manifesti di Marinetti, e lascia leggibile ogni parola.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Decorazione futurista editoriale](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/decorazione-futurista-editoriale). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install decorazione-futurista-editoriale@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install decorazione-futurista-editoriale@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Con altri agenti copia la cartella `skills/decorazione-futurista-editoriale` tra le skill dell'agente, per esempio in `~/.codex/skills/decorazione-futurista-editoriale`.
